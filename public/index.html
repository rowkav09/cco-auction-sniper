Sign-in happens in a real Chrome window this app opens and controls (case-clicker.com is behind Cloudflare bot protection that blocks plain script requests, even with a valid cookie -- a real browser is the only thing that gets through). First run: log in in that window when it appears. After that, the session is remembered in data/browser-profile/ and it won't ask again.
CCO extends an auction's deadline if a bid lands in the final minute (anti-snipe), so snipe mode mostly just delays the same outcome autobid gets you immediately. Autobid is the default for a reason.
Market value = your pricedata script's dollar estimate for the skin, converted to tokens. Auctions are bid in tokens but the pricedata sheet is in dollars, so a $→tokens rate is needed. By default it self-calibrates from CCO's own comparable sales (a sample is collected whenever an auction has enough recent sales); set a manual rate below to skip waiting on that.
How much the bot is allowed to have at risk at once. Gated against what's currently held (auctions you're actively leading), not a lifetime total -- being outbid releases the hold immediately, same as it does on the real site, so this number reflects live exposure rather than growing forever.
